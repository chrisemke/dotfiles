# dotfiles, home sweet home

This repo is my home directory, or at least the parts of it worth keeping.

The layout follows `$HOME`, just without the leading dot, so things go
where you'd expect:

| here     | there       |
|----------|-------------|
| `config` | `~/.config` |
| `local`  | `~/.local`  |

The exceptions are `dev`, which holds the guix manifests for my dev
shells, and `scripts`, which is stuff for managing the repo itself.

The main repo lives at [git.sr.ht](https://git.sr.ht/~krisque/dotfiles) and is mirrored to Codeberg, GitHub and
GitLab.
